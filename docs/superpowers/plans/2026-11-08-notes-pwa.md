# Elegant Stylus & Keyboard PWA Notes App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an elegant, minimalist Progressive Web App (PWA) note-taking application optimized for Samsung Galaxy Tab (S Pen) and iPad (Apple Pencil) with pressure-sensitive handwriting, scribble-to-text recognition, multi-color keyboard rich text editing, local-first offline storage, and automated Cloudflare Pages deployment via GitHub.

**Architecture:** Modern client-side React 19 + TypeScript single-page PWA with Vite. Ink engine uses HTML5 2D Canvas with `PointerEvent.getCoalescedEvents()` for 120Hz high-precision stylus tracking, palm rejection, and dynamic pressure/velocity stroke smoothing. Rich text editing handles color-coded blocks, while a dedicated OCR engine (Tesseract.js worker + image preprocessing + optional Gemini AI integration) transcribes handwritten scribbles into text. Notes and ink strokes persist locally in IndexedDB.

**Tech Stack:** 
- Frontend: React 19, TypeScript, Vite, Tailwind CSS, Lucide React
- Stylus & Canvas: PointerEvents API (coalesced events, pressure, tilt), Catmull-Rom / Bézier stroke smoothing
- Recognition: Client-side Tesseract.js (worker-based offline OCR) + optional Gemini API hook for advanced handwriting-to-text
- Storage: IndexedDB (idb-keyval / Dexie pattern) with local-first auto-save
- PWA: `vite-plugin-pwa`, Service Worker with CacheFirst offline caching, Web App Manifest
- Deployment: GitHub Actions + Cloudflare Pages (`wrangler` / Cloudflare Pages CI)

**Spec:** User requirements for Galaxy Tab S Pen & iPad Apple Pencil support, scribble-to-text conversion, multi-color text writing, PWA installation, elegant design, and Cloudflare Pages auto-deployment.

## Global Constraints
- Must function 100% offline as an installable PWA on both iPadOS and Android.
- Stylus input must distinguish between pen and touch (`e.pointerType === 'pen'` vs `'touch'`) with palm rejection.
- Support pressure sensitivity (`e.pressure`) for dynamic stroke thickness.
- Support eraser tip / S Pen barrel button (`e.buttons === 32` / secondary pointer button).
- Support multi-color text and ink palettes with elegant design aesthetics.
- Cloudflare Pages configuration must output static build assets in `dist/`.

## Review Focus
1. Stylus latency and jitter on high-refresh-rate displays (Galaxy Tab 120Hz / iPad ProMotion): must use `e.getCoalescedEvents?.()` when available.
2. Palm rejection: accidental hand rests should not create rogue ink lines when the pen is active.
3. Offline service worker caching: application must load and save notes without network connectivity.
4. Canvas resolution scaling: crisp lines on high-DPI Retina/AMOLED displays without blurriness (`window.devicePixelRatio`).
5. Scribble recognition accuracy: clear stroke pre-processing (contrast normalization, canvas trimming) before OCR extraction.
